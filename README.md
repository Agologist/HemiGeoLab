# Hemi Geometry Lab

Signal-true **stereo vector scope** for multi-channel tones.

Geometry is computed from the same model as the audio intent: each channel’s **frequency, gain, phase, pan, H2/H3**. No forced sacred overlays — circle-like or mesh-like figures **emerge** from real relations (or don’t).

## Run

```bash
cd ~/Projects/hemi-geometry-lab
npm install
npm run dev
```

## Experiment

1. **Play** with headphones  
2. Try seeds: Circle region (1:1 · 90°), Line (0°), 3:2 mesh, binaural Δ10 Hz, +H2  
3. Tweak **phase**, **ratio**, **H2/H3** — watch the path change  
4. **Mark finding** to save interesting states  

## Honesty

X = left-weighted partials · Y = right-weighted partials. Classifications (circle region, mesh, drifting beat…) describe the **signal**, not cosmic law.
